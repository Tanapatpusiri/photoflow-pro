# PhotoFlow Pro

Mobile-first sports photography gallery for photographers, teams and parents.

## Included in this first release

- Public event gallery with search and category filters
- Face-search entry flow and privacy notice
- Photographer registration and role-based login UI
- Photographer studio dashboard, album creation and multi-file upload flow
- Responsive mobile and desktop layouts

The current release provides a complete interactive frontend. Persistent uploads, authentication, AI face matching and payments require backend services and credentials before production use.

Production deployment is managed by Vercel from the `main` branch.
